# 絵文字 → SKK 読み 生成ルール

入力: `in-NN.jsonl`（1行1絵文字。emoji / en(Unicode英名) / ja(CLDR日本語名) / kw(CLDRキーワード) / subgroup）
出力: `out-NN.jsonl`（同じ順・同じ件数。1行1絵文字の JSON）

```json
{"emoji":"😂","name":"うれし泣き","readings":["うれしなき","なきわらい","わらいなき","わら","くさ","ばくしょう","おおわらい"]}
```

- `name`: 候補の注釈に出す日本語名。基本は CLDR の `ja` を使い、不自然・誤訳・英語直訳すぎる場合のみ自然な日本語に直す。`/` と `;` は使用禁止。
- `readings`: SKK の送りなし見出し語。**ひらがなと長音「ー」のみ**（例外: 英字略語は小文字ASCII可 例 `sos`,`ok`,`ng`,`atm`,`wc`,`id`,`vs`,`tm`,`abc`,`cl`,`ufo`。数字は可 例 `100`）。
  1. 先頭は `name` の直訳読み（例「にっこりわらう」）。カタカナ語はひらがなにする（「スマイル」→「すまいる」）。
  2. 続いて日本人が自然に打ちそうな別名を 3〜8 個程度。対象物の一般名・俗称・ネットスラング・感情の言い方・用途（例 🙏 → おねがい, ありがとう, いただきます, おがむ, がっしょう / 🥺 → ぴえん, うるうる / 🔥 → ほのお, ひ, えんじょう, もえる, あつい）。英名のカタカナ読みも有用なら入れる（例 🍎 → あっぷる）。
  3. 汎用すぎる1文字読み（「て」「め」「ひ」程度はOK）は本当に代表的な場合のみ。キーワード中の漠然とした語（「顔」「記号」など）は入れない。
  4. 国旗: 国名の読み（「にほん」「にっぽん」）＋「〇〇のこっき」「〇〇のはた」。国の通称・略称も（例 🇺🇸 あめりか, べいこく, がっしゅうこく, せいじょうき）。
  5. キーキャップ等: 🔟→「じゅう」「10」、#️⃣→「しゃーぷ」「いげた」など。
  6. 重複しない。濁点・拗音の表記ミスに注意（ぢ/じ、づ/ず は現代仮名遣い）。
- 全件必ず出力する。JSON 1行ずつ、UTF-8。
